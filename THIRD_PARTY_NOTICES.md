## HyperHDR Plasma effect

AmbiSun's Plasma-style UI background is based on the algorithmic approach used by the HyperHDR
`Animation_Plasma` effect (80×45 field, HSV hue palette and sinusoidal plasma field).

HyperHDR is developed by awawa-dev and contributors and is distributed under the MIT License.

Project: https://github.com/awawa-dev/HyperHDR

The AmbiSun UI renderer is an independent JavaScript adaptation intended for a smooth TV UI
preview; it does not copy HyperHDR's C++ source verbatim.
